# remoterabbit/open-docs

Homebrew tap for [open-docs](https://github.com/remoterabbit/open-docs).

```sh
brew install remoterabbit/open-docs/open-docs
```

Or, in a `Brewfile`:

```ruby
tap "remoterabbit/open-docs"
cask "open-docs"
```

`Casks/open-docs.rb` is generated by GoReleaser on each open-docs release; do not edit it by hand.
