# Remoterabbit Open-docs

## How do I install these formulae?

`brew install remoterabbit/open-docs/<formula>`

Or `brew tap remoterabbit/open-docs` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "remoterabbit/open-docs"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
